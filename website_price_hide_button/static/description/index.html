Price Hide - Secure Product Pricing

Restrict product price visibility to authenticated users only

Key Benefit: Protect your pricing strategy and encourage customer registration

This essential module for Odoo Website hides product prices from visitors who aren't logged in, creating a professional B2B experience and encouraging user registration.

Core Features:

  • Automatic price hiding on product pages for public users
  • Displays custom login prompts instead of prices
  • Seamless integration with Odoo eCommerce
  • Preserves all functionality for logged-in users
  • Mobile-responsive design

How It Works:

1

Visitor browses products

2

Price fields automatically hidden

3

Login/Register prompts displayed

Technical Specifications:

  • Compatible with Odoo 17, 18
  • Doesn't modify core Odoo functionality
  • Lightweight design (~50KB)
  • Multi-language support

Sync Odoo Data Effortlessly

Excel Odoo Connector links Odoo with Excel or LibreOffice Calc, allowing automatic data syncing. By generating a URL or ODC file users can ensure smooth data exports for sales reports, customer info, or accounting data. The ODC files can only be used to connect Excel not LibreOffice calc. The connector simplifies data management by allowing users to create excel templates for quick and easy exports without doing it manually.

Secure Data Transfer & Management

Security is an important feature of Excel Odoo Connector. It generates access tokens to safeguard exported data and keeps track of access history to monitor connected IPs. If any unauthorized access is found, refreshing the token will disconnect all current sheets, ensuring only authorized users can access the data. This helps keep your Odoo data safe at all times.

Customizable Templates for Dynamic Exports

With Excel Odoo Connector, users can create multiple excel templates based on their specific needs. You can filter the data to export only what is necessary and schedule regular exports to keep your Excel sheets updated. This flexible setup allows users to easily manage data from different Odoo modules and sources.

Customizable excel templates

  • Create templates for specific Odoo modules like sales, accounting, and customer data.
  • Set rules for the data you want to export, giving you full control over what is exported.
  • Excel Odoo Connector lets you quickly switch templates between active and inactive states.

Data Filtering and Export Flexibility

  • Add filters to narrow down the data you want to export, making it easier to manage.
  • Pick which fields to include in your export, so your report only shows what’s important.
  • Use special rules to customize the data you export, getting exactly what you need from Odoo.

Secure Token-Based Access

  • Creates a unique access token for every export to keep the connection safe.
  • You can refresh the token anytime to block old connections and stop unauthorized access.
  • It tracks all connections and shows IP logs in the access history tab.

Seamless Data Connection with Excel and LibreOffice

  • Download an ODC file to connect Excel directly with your Odoo for real-time data updates.
  • Create a URL to sync Odoo data automatically with Excel and LibreOffice Calc.
  • Easily export and sync Odoo data across both platforms for simple reporting and data management.
